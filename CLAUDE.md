# Project Instructions

## Development workflow

Before modifying the codebase:

1. Explain the proposed implementation.
2. List all files that will be created or modified.
3. Wait for explicit user approval.
4. Only after approval, implement the changes.

Never automatically create, modify, or delete files without explicit approval.

## Project conventions

- Use Python with type hints.
- Use FastAPI for REST APIs.
- Keep the project structure clean and production-oriented.
- Add tests for new functionality.
- Do not add unnecessary dependencies.
- Prefer simple and readable implementations.
